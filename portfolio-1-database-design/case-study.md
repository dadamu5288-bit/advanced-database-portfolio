# CASE STUDY: TrustLink Microfinance Bank (simulated)

# 

# Nature of the business:

# A retail bank that lets customers open savings, current and

# fixed-deposit accounts, and move money through deposits,

# withdrawals and transfers.

# 

# Users of the database:

# Customers, bank tellers, branch managers and auditors.

# 

# Major data stored:

# Branches, customers, account types, accounts, transactions

# (the ledger) and transfers.

# 

# Key operations the database supports:

# \- Open accounts

# \- Deposit and withdraw money

# \- Transfer funds between accounts

# \- Reverse failed transfers

# \- Audit account balances

# \- Produce account statements
